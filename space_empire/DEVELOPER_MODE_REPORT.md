# Space Empire — Developer Mode / Test Mode

## Реалізовано

- Окремий пункт **Developer Mode / Тестування** в головному меню.
- Developer Mode запускає нову тестову сесію в окремому каталозі `saves/developer/`.
- Окремий JSON save `developer_save.json` та окремий `technology_progress.json`.
- Нормальний save `saves/space_empire_save.json`, звичайний файл технологій і їхні backup/archive не використовуються для тестового слота.
- Окреме вікно Developer Mode; F12 приховує/показує панель.
- Ресурси: додавання/зняття для вибраного ресурсу, фіксовані швидкі кнопки, точне встановлення кількості через клавіатуру.
- Миттєве завершення черги будівництва, миттєве будівництво вибраної споруди та миттєве покращення вибраної споруди.
- Одноразове прискорення виробництва, миттєве завершення активного дослідження, розблокування всіх технологій.
- Розблокування каталогу споруд, корабельного виробництва (через developer-only ангар), розблокування всіх глав кампанії.
- Вибір місії, примусове завершення поточної місії з її штатною винагородою, перехід на наступну місію та скидання станів місій.
- Перемикачі швидкості 1x/2x/5x/10x/50x/100x, Pause/Resume.
- Відображення глави, поточної місії, умови поточної місії, запасів ресурсів, швидкості, статусу та повідомлень.
- Повний перелік місій і діагностичних нестач доступний через `mission_diagnostics()`.

## Клавіші Developer Mode

| Клавіша | Дія |
|---|---|
| F12 | Показати/сховати Developer Mode |
| F10 | Pause/Resume |
| F9 | Перемкнути швидкість по циклу 1x → 2x → 5x → 10x → 50x → 100x |
| F8 | Вибрати наступний ресурс |
| F2 | Ввести точну кількість вибраного ресурсу; Enter застосовує |
| F3 / F4 | Додати / зняти 100 одиниць вибраного ресурсу |
| F6 | Вибрати наступний тип споруди |

## Автоматизована перевірка кампанії — важливе обмеження

Реалізовано консервативний звіт-діагностику `campaign_test_report.txt`: він проходить усі 8 глав і 16 місій, читає реальні каталоги споруд/умови/нагороди, показує вимоги, поточні запаси, виробництво, вартість споруд і частину залежностей. Він **не додає ресурси, не завершує місії і не підміняє економіку**.

Це поки що не повноцінний headless end-to-end симулятор усієї кампанії від чистого save: цілі на видобуток, флот, відкриття систем, колонії, технології та випадкові події не проганялися автоматично через часову модель. Тому звіт не робить висновку, що кожна місія гарантовано прохідна. Повний автоматизований послідовний прогін кампанії залишається незавершеним.

## Зміни в коді

- `launcher.py` — пункт меню та передавання прапорця Developer Mode.
- `game.py` — окремі шляхи збережень, тестовий режим часу, пауза, виведення панелі, синхронізація миттєво завершених споруд.
- `campaign/campaign_manager.py` — ізольований developer override для відкриття всіх місій; стандартний алгоритм кампанії не змінений.
- `developer/dev_mode.py` — новий контролер, панель, команди ресурсів/будівництва/технологій/кампанії/швидкості/діагностики.
- `developer/__init__.py` — пакет.
- `tests/test_developer_mode.py` — 7 додаткових перевірок структури та ізоляції.

## Runtime-обмеження

У середовищі не встановлений `pygame`. Через це гру не вдалося запустити графічно. Не підтверджені фактичні кліки/позиціонування панелі, створення тестового save через UI, поведінка швидкостей у runtime, збереження після перезапуску процесу та відсутність регресій нормальної гри під час реального запуску. Ці твердження не позначаються як перевірені.

## Файлова безпека

Під час розробки жоден файл із попереднього ZIP не видалено. Developer save path відокремлений від звичайного шляху. Звичайна кампанія зберігає початковий шлях та стандартну поведінку.
